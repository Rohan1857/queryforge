# Visual Directions Library

Use this document to choose a concrete design direction before generating UI.

Do not say only “modern”, “clean”, “premium”, or “minimal”. Those words are too vague. Pick a direction with constraints.

## 1. Native macOS Utility

### Best for

- desktop apps,
- menu bar tools,
- productivity utilities,
- dictation apps,
- local-first tools,
- privacy-first software.

### Mood

Calm, precise, fast, trustworthy, native, unobtrusive.

### Palette

- graphite,
- off-white,
- macOS gray,
- muted blue,
- subtle green for local/privacy status,
- avoid loud purple.

### Typography

- Apple system font is acceptable and intentional here,
- clear label hierarchy,
- compact settings typography,
- avoid huge SaaS display headlines.

### Layout

- menu bar panel,
- compact overlay,
- preferences window,
- split settings pane,
- command palette,
- status strip.

### Motion

- functional only,
- listening/recording state,
- small panel transitions,
- reduced-motion safe.

### Avoid

- marketing SaaS hero,
- purple gradients,
- neon glow,
- emoji icons,
- bento grid as identity.

## 2. Developer Tool / CLI Companion

### Best for

- coding tools,
- MCP tools,
- context systems,
- API platforms,
- local dev utilities.

### Mood

Sharp, technical, legible, efficient, credible.

### Palette

- dark graphite or off-white,
- muted cyan/blue/green accent,
- terminal-inspired neutrals,
- semantic status colors.

### Typography

- readable sans for UI,
- mono for commands, paths, logs, and code,
- strong label/data distinction.

### Layout

- command center,
- docs-like shell,
- split panes,
- terminal preview,
- activity timeline,
- API key/config panels.

### Motion

- state transitions,
- command execution feedback,
- no decorative floaty motion.

### Avoid

- “AI magic” purple,
- emoji feature cards,
- generic marketing page rhythm,
- fake terminal if it does not serve a purpose.

## 3. Enterprise Control Plane

### Best for

- admin dashboards,
- orchestration systems,
- internal platforms,
- compliance tools,
- enterprise SaaS.

### Mood

Reliable, structured, calm, operational, high-trust.

### Palette

- neutral base,
- restrained blue/green accents,
- clear semantic colors,
- high contrast for data states.

### Typography

- clear sans,
- dense tables,
- labels and values clearly separated,
- avoid overly playful display fonts.

### Layout

- sidebar nav,
- top status bar,
- dense cards only when useful,
- tables,
- filters,
- detail drawers,
- audit trails.

### Motion

- minimal,
- drawer/panel transitions,
- loading and status feedback.

### Avoid

- huge empty hero,
- neon glow,
- dramatic gradients,
- decorative bento grids.

- threat monitoring,
- AI safety tooling,

### Mood

### Palette

### Typography

- mono for IDs/logs,
- strong status labels.

### Layout

- evidence panel,
- risk score module,
- timeline,
- decision controls,
- audit log.

### Motion

- state changes,
- new incident arrival,
- alert escalation,
- no decoration.

- entity pages,

### Best for

- wellness apps,
- self-experiment apps,
- journaling,
- lifestyle guidance,
- calm consumer mobile apps.

### Mood

Warm, grounded, human, spacious, premium, safe.

### Palette

- warm neutrals,
- muted greens,
- soft clay,
- cream,

### Typography

### Layout

### Best for

- token research,

- market intelligence,
- risk monitoring.

### Mood

Sharp, skeptical, data-heavy, investigative, fast.

### Palette

- dark or light neutral,
- semantic risk colors,
- amber for warnings,
- green for verified delivery,
- red only for high risk.

### Typography

### Layout

### Motion

- subtle data refresh,

- floating coins,
- fake futuristic neon,

## 8. Consumer Creator Tool

### Best for

- video/audio creation,
- writing tools,
- design tools,
- creator productivity.

### Mood

Expressive, fast, creative, friendly, but still polished.

### Palette

- can be brighter,
- must avoid default AI purple unless branded,
- use one distinctive accent.

### Typography

- more personality allowed,
- clear UI labels,
- avoid novelty fonts in controls.

### Layout

- canvas + inspector,
- timeline,
- prompt/control area,
- preview-first UI,
- export actions.

### Motion

- direct manipulation,
- preview transitions,
- generation state,
- avoid confetti unless earned.

### Avoid

- generic magic wand UI,
- emoji overload,
- too many playful effects in serious workflows.

## 10. Minimal Editorial Product

### Best for

- thoughtful SaaS,
- writing tools,
- publishing platforms,
- premium B2B with strong copy,
- products where words carry the brand.

### Mood

Quiet, authored, confident, typographic, restrained.

### Palette

- paper/off-white or soft neutral,
- ink/near-black text,
- one restrained accent,
- avoid loud gradients.

### Typography

- editorial sans or serif-sans pairing,
- strong display/body contrast,
- generous line height for long copy.

### Layout

- editorial split,
- asymmetric headline column,
- proof and narrative columns,
- few panels, strong typographic rhythm.

### Motion

- almost none,
- focus on reading flow.

### Avoid

- hero + three cards,
- purple AI palette,
- decorative glow,
- card grid as identity.

## 11. Playful Consumer App

### Best for

- casual mobile apps,
- social/community products,
- games-adjacent tools,
- youth-oriented consumer products.

### Mood

Friendly, energetic, approachable, memorable — but still designed.

### Palette

- brighter accents allowed,
- must avoid default AI purple unless branded,
- cohesive limited palette, not rainbow chaos.

### Typography

- personality allowed in display,
- clear readable UI labels,
- no novelty fonts in controls.

### Layout

- guided flows,
- single-focus screens,
- playful illustration only when intentional.

### Motion

- feedback on tap/state,
- delight in earned moments,
- no scroll-reveal overload.

### Avoid

- emoji as icon system,
- generic SaaS landing rhythm in-app,
- neon glow without product reason,
- rounded-3xl on everything.
