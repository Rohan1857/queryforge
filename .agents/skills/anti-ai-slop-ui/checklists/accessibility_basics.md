# Accessibility Basics Checklist

This skill is not a full accessibility audit, but generated UI should meet basic standards.

## Contrast

- [ ] Text has sufficient contrast.
- [ ] Secondary text is readable.
- [ ] Accent text is not used as the only way to communicate meaning.
- [ ] Disabled states remain understandable.

## Keyboard

- [ ] Interactive elements are reachable by keyboard.
- [ ] Focus states are visible.
- [ ] Modals/drawers can be closed with keyboard.
- [ ] Focus order follows visual order.

## Motion

- [ ] Motion is not required to understand the UI.
- [ ] Reduced motion is considered.
- [ ] No excessive flashing/pulsing.

## Semantics

- [ ] Buttons are buttons.
- [ ] Links are links.
- [ ] Form inputs have labels.
- [ ] Icons have accessible names when needed.

## Responsive behavior

- [ ] Layout works on small screens.
- [ ] Tables have a usable mobile strategy.
- [ ] Touch targets are large enough.
- [ ] Critical actions remain visible.
