# Dashboard Checklist

Use this for SaaS dashboards, admin panels, monitoring tools, analytics products, and control planes.

## Information architecture

- [ ] Is the primary user task obvious?
- [ ] Are navigation levels clear?
- [ ] Are filters, search, and drilldowns placed logically?
- [ ] Is the density appropriate for the user type?

## Data hierarchy

- [ ] Are KPIs meaningful, not decorative?
- [ ] Are tables readable and scannable?
- [ ] Are status labels clear?
- [ ] Are empty/loading/error states defined?

## Layout

- [ ] Does the layout support actual operations?
- [ ] Are cards used only where they clarify grouping?
- [ ] Is there a detail drawer/panel when useful?
- [ ] Are audit/history/evidence areas available if trust-heavy?

## Visual system

- [ ] Does it avoid default gray-card shadcn dashboard look?
- [ ] Are semantic colors used consistently?
- [ ] Is typography optimized for scanning?
- [ ] Is mono used for IDs/logs/code where useful?

## Motion

- [ ] Are transitions functional?
- [ ] Are live updates understandable?
- [ ] Is there no decorative animation noise?

## Anti-slop final check

- [ ] Does it look like a real operational tool, not a UI kit demo?
- [ ] Would the target user trust it with important decisions?
- [ ] Are visual decisions justified by workflow?
