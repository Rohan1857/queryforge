# Landing Page Checklist

Use this for marketing pages, launch pages, SaaS pages, and product homepages.

## Positioning

- [ ] Does the hero state a concrete product promise?
- [ ] Does it avoid generic “Transform your workflow with AI” language?
- [ ] Is the primary audience obvious?
- [ ] Is the primary CTA obvious?

## Hero

- [ ] Does the hero avoid default centered gradient headline unless justified?
- [ ] Is there a real product visual, workflow, or proof object?
- [ ] Is the layout distinctive?
- [ ] Does the above-the-fold area show what the product actually does?

## Structure

- [ ] Does the page avoid generic hero + three cards + bento + FAQ rhythm?
- [ ] Are sections ordered around user understanding, not template convention?
- [ ] Is there a product story or workflow?
- [ ] Is there credible proof?

## Visual system

- [ ] Is the palette product-specific?
- [ ] Is typography intentional?
- [ ] Are icons coherent and not emoji-based?
- [ ] Is motion restrained and functional?

## Trust

- [ ] Are privacy/security/local-first claims supported if present?
- [ ] Are integrations/providers shown clearly?
- [ ] Are limitations or modes explained honestly?
- [ ] Does the page avoid fake hype?

## Anti-slop final check

- [ ] No default purple/blue gradient identity
- [ ] No emoji feature icons
- [ ] No generic shadcn demo look
- [ ] No meaningless glow/aurora blobs
- [ ] No identical three-card feature block as the main explanation
