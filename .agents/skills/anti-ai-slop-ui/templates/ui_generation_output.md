# UI Generation Output Template

Use this structure when generating UI.

## 1. Design direction

State the chosen visual direction and why it fits the product.

## 2. Token decisions

Summarize:

- palette,
- typography,
- spacing,
- radius,
- elevation,
- icons,
- motion,
- density.

## 3. Layout strategy

Describe the chosen layout pattern and how it avoids the generic AI/SaaS default.

## 4. Implementation

Provide implementation plan, code, or file changes depending on task.

## 5. Anti-slop check

Score and explain:

- AI Slop Score: 0-10
- Distinctiveness Score: 0-10
- Implementation Readiness Score: 0-10

List any remaining risks.

## 6. Remaining trade-offs

List conscious compromises, unresolved risks, and what to revisit before shipping. If anything still looks generic, specify what to change.
