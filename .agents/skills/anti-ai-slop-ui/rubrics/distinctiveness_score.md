# Distinctiveness Score Rubric

Distinctiveness Score measures how intentional, product-specific, and memorable the UI feels.

Scale:

- 0 = completely generic
- 10 = strongly product-specific and recognizable

## Categories

Score each category 0-2 points.

### 1. Product fit

0 = could belong to any SaaS product
1 = somewhat aligned with product category
2 = clearly designed for this specific product and audience

### 2. Visual system clarity

0 = no visible system beyond defaults
1 = some token decisions are visible
2 = coherent palette, type, spacing, radius, icons, and motion

### 3. Layout character

0 = default layout
1 = adapted common layout
2 = layout structure supports the product's actual workflow or story

### 4. Typographic identity

0 = default typography
1 = readable but not memorable
2 = typography supports tone, hierarchy, and product context

### 5. Signature moments

0 = no memorable element
1 = one somewhat distinctive component or section
2 = at least one strong product-specific visual/interaction pattern

## Total score

0-2: Generic. Redesign needed.

3-4: Weak. Has some direction but not enough character.

5-6: Decent. Acceptable for MVP but not strong brand/UI.

7-8: Strong. Clearly intentional and product-specific.

9-10: Excellent. Distinctive, coherent, and memorable.

## Required action

If below 7, propose at least three specific improvements.
