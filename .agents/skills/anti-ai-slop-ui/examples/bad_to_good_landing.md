# Bad to Good: Landing Page

## Scenario

A coding agent is asked to build a landing page for an AI productivity tool.

## Bad output

### Description

- centered hero,
- giant gradient headline,
- “Transform your workflow with AI”,
- two CTA buttons,
- three equal feature cards,
- purple-to-blue gradient accents,
- emoji feature icons,
- rounded-2xl cards everywhere,
- vague copy,
- no product screenshot,
- no workflow proof.

### Why it feels like AI slop

It has no product-specific visual identity. It looks like the average of thousands of SaaS landing pages. The layout does not explain the product, the color palette screams generic AI, and the cards are interchangeable.

### AI Slop Score

9/10

### Distinctiveness Score

2/10

## Better output

### Revised direction

Developer-focused productivity tool with a command-center layout.

### Visual system

- palette: graphite, off-white, muted cyan accent,
- typography: UI sans + mono for commands and snippets,
- layout: asymmetric hero with product UI screenshot,
- icons: Lucide or custom line icons,
- motion: command execution feedback only.

### Structure

1. Asymmetric hero:
   - left: concrete promise,
   - right: real UI state or command center mock.
2. Workflow strip:
   - input -> agent action -> reviewed output.
3. Proof section:
   - examples, integrations, measurable outcomes.
4. Feature section:
   - not three equal cards; grouped by workflow stage.
5. CTA:
   - connected to a concrete action.

### Why it is better

It explains the product through mechanism and interface. The user sees what the tool does, how it behaves, and why it exists. The visual system is quieter and more specific.

### AI Slop Score

3/10

### Distinctiveness Score

8/10
